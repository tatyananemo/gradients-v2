# Текущая поставка V4-Dark-Core

Приоритетный документ сборки и подключения — [README](../README.md).
Версия алгоритмов: `d62ae67`; исходные алгоритмические compiler inputs фиксируются
в [source-manifest.json](source-manifest.json). Поставку воспроизводит вся эта папка.

## Визуал и поведение

Dark Touch — принятый пользователем вариант Light Structure: тёмное ядро, мягкое цветное
золотисто-оранжевое тело, плавное угасание и воздействие на жидкость. Используется исходная
композиция `dd08828`: `B * touchTransmission + touchEmission` с теми же существующими полями
касания. Нет белого центра оригинальной V4-Optimized. Специальные поздние коррекции Hue,
яркости и внутреннего склона **не включены**. Контурность/оливковое восприятие некоторых
золотистых полутонов не объявляются исправленными: сохраняется именно принятый d62ae67.
MAIN, IDLE, форма, Gaussian blur, distortion, жесты, reset и прогресс сохранены.

Light — оригинальный визуал. MAIN/CONTACT выбираются специализированными compute pipelines:
function constant 102, route 3/4. Dark сохраняет route 1/2; fallback — 0. Цветовые значения,
математические формулы, текстуры, IOSurface-пул, количество in-flight кадров и публичный API
при этой оптимизации не менялись. Compositor и анализатор подписи сохраняют mode 0;
предрасчёт/background — mode 3 для function constant 101.

## Подтверждения и пределы

[Короткие физические контроли](device-control-results.json) относятся к SDK d62ae67, Release,
iPhone 14, iOS 26.7. RAM-измеритель сохранял данные после остановки; его код не входит в SDK.
Не путать GPU command-buffer elapsed со временем исполнения шейдера: он включает ожидания.
При упаковке новые тесты на iPhone/Simulator не выполняются.

В существующем Mac-сравнении специализации Light проверено 37 целевых кадров: Dark побайтово
точен; в 29 кадрах Light оставались технические расхождения до 1/255, максимум 26 компонентов
из 11 849 760 на кадр. Поэтому не заявляется полная pixel-exact идентичность Light старой
неспециализированной сборке. Этот кандидат принят после проверки на iPhone. Исторические GPU/mask/
component/UI suites сохранены; не утверждается, что все они заново пройдены на d62ae67.

Длительная стабильность 60 FPS и отсутствие нагрева не доказаны. Перенос в банковский продукт,
внешняя модель прогресса и криптографические операции находятся за пределами этой поставки.
