## Заполнение и поведение

В `9eb2ecc` изменены только gain накопления ×4 и cap 0,105/с. Touch credit 0,013,
интерполяция 0,48 с, idle 3 с, release 0,30/0,82 с, возврат idle 0,42 с и reset 0,35 с сохранены.
Существующий Debug/Release CPU replay с обычными/медленными/быстрыми движущимися
траекториями на 30/40/60/120 Hz: target 100% за **9,40–9,50 с**, rendered — **9,883–9,967 с**.
Idle, неподвижный hold и release не добавляют target progress; reset проверен.
512 input events, 966 state/history/progress checks, 3 864 сравнений frame arguments в каждом mode.
Это replay, не секундомер реального пальца; паузы и слишком медленное движение удлиняют заполнение.

## Границы готовности

- Dark близок к 60 в коротких свайпах; стабильность во всех состояниях/размерах и длительный idle
  последнего кандидата не доказаны. Light остаётся около 57–58 FPS с редкими двойными интервалами.
- Температура корпуса в °C не измерялась. Старый 6c80005-based кандидат достигал serious примерно
  через 70 с; отсутствие проблемы у 1b3c287 длительным тестом не подтверждено.
- Включать весь V4-Optimized: optimized build требует DeviceComparison overlays, а не только
  базовый GradientsKit-V4.xcodeproj. SPM/XCFramework отсутствуют; public API без изменений.
- External actual progress/completion API, privacy/distribution/доступность/layout требуют
  отдельного согласования; новых обещаний интеграции или API КриптоПро здесь нет.
- Исходники/ресурсы/проекты копии совпадают с кандидатом. При этой актуализации изменены только
  документы, build-verification metadata и два устаревших сообщения упаковочного проверяльщика;
  ни приложение, ни новый экспорт не собирались и не запускались.
