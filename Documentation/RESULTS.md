## Физический iPhone 14 / A15

Прогон 29.10.2026: 6 секунд автосвайпа после 3 секунд warm-up, стартовый progress 63% с естественным
дальнейшим ростом. Яркость 0,35, Low Power off, 45 секунд остановленного охлаждения между запусками,
без Instruments. Полный диапазон состояний этими короткими цифрами не покрыт.

| Dark, старт 63% | 45,159 | 33,351 / 33,373 | 25,543 | 7,251 | 10,366 |
| Dark, повтор со старта 63% | 45,490 | 33,352 / 33,387 | 25,307 | 7,243 | 10,514 |

| Light, старт 63% | 57,950 | 16,708 / 33,380 | 21,876 | 0,002 | 13,781 |

В этих запусках thermal state **nominal**, Metal command errors не зарегистрированы.
Command buffer duration включает ожидания/очереди и не равен чистому shader execution;
его нельзя сложить с mask CPU и drawable wait для получения полного кадра.
Предыдущий сопоставимый Dark 0efba7a — 43,126 FPS. Это улучшение около 4,7–5,5%, а не достижение 60.

Длительный тепловой тест **этого commit не выполнен**. Более ранний 6c80005-based кандидат
в Dark 63% idle достигал serious примерно через 70 секунд от запуска; последняя версия не
доказана ни повторяющей, ни устранившей это поведение. Температура корпуса в °C не измерялась.
Не утверждать отсутствие нагрева по одному nominal либо субъективно прохладному корпусу.

## Что остаётся перед конечным продуктом

1. Dark не соответствует целевым стабильным 60 FPS; Light близок, но равномерность 60 не гарантирована.
2. Длительное тепловое поведение текущей версии не проверено; CPU CG/CI masks, background GPU и drawable
   backpressure остаются ограничителями. Финальная передача их не переписывает.
3. Актуальная оптимизированная сборка пока требует source overlays из Development/DeviceComparison.
4. Контракт фактического progress/result от КриптоПро отсутствует; demo progress не является результатом SDK КриптоПро.
5. Privacy manifest/required-reason declarations, license/distribution и поддерживаемые embedded layout/accessibility
   должны быть согласованы владельцем конечного приложения. Новые API или предположения здесь не добавлены.
6. Размер шейдера проходит порог с небольшим запасом; при смене toolchain или shader входов его нужно проверять снова.
